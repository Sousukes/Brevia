# 第十八轮：补齐前三步引导左侧动画

用户明确要求补齐语言、权限、模型与存储页的动画。五步左侧动画现已接入实际应用，右侧设置的布局、选项和操作保留；第十七轮关于前三页保持静态的范围由本轮覆盖。

## 动画内容

| 页面       | 时长  | 关键状态                                                       |
| ---------- | ----- | -------------------------------------------------------------- |
| 语言       | 12 秒 | 0 秒另一语言的会议列表；3 秒选择当前语言；3.9 秒完成文字切换   |
| 权限       | 12 秒 | 0 秒待授权；2 秒请求；4 秒已允许；5 秒开始显示声音输入         |
| 模型与存储 | 14 秒 | 0 秒语音识别模型；2 秒选中；5 秒模型文件夹；9 秒会议录音文件夹 |
| AI 功能    | 62 秒 | 保留上一轮真实会议界面的纪要与智能笔记演示                     |
| 手机连接   | 14 秒 | 保留手机录音、电脑识别、手机显示转写的演示                     |

前三页使用实际应用的会议列表、权限状态、模型选择和保存位置视觉语言。模型用通用名称说明用途，不伪造具体型号、下载进度或安装完成。权限页只展示流程，不触发操作系统授权；系统音频保留可选含义。模型文件与会议录音分别呈现。

五页共同使用 logo＋Brevia、横向五步导航及八种语言词条。动画支持暂停、重播和减少动态效果；退出页面会销毁时间轴。快速切换语言或离开引导时，过期延迟回调不会重新挂载动画。

## 应用与预览

完全退出已有 Brevia 进程后运行 `npm run start:fresh`，从语言页即可看到动画，再按右侧正常操作进入下一步。已有进程存在时，Electron 单实例行为会聚焦原窗口。

[统一播放器](videos/onboarding-motion/preview.html)新增前三页入口，默认打开语言动画。前三页直接复用应用组件和时间轴，避免维护另一套效果。用 `node scripts/sync-onboarding-preview.mjs` 同步应用词条、组件与动效到预览；生成快照不可手工修改。原九秒预览仍可通过播放器入口查看。
