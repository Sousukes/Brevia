# 第十九轮：引导共用三画面轮播

按用户最终选择，所有引导页共用录音、转写、纪要三个画面。`videos/onboarding-motion/assets/reference.png` 作为第一帧视觉基准，重建白色录音卡片、产品周会标题、红色录音点及自然声音曲线。五步不再维护不同动画，独立 AI／手机演示移除，右侧设置保持原样。

## 轮播与一致性

| 时间轴  | 画面                                         |
| ------- | -------------------------------------------- |
| 0 秒    | 录制会议：保留原始录音，自然声音曲线轻柔变化 |
| 2.35 秒 | 转写文字：曲线变为文字基线，整句字幕淡入     |
| 5.35 秒 | 生成纪要：字幕淡出，讨论要点与行动事项淡入   |
| 8.1 秒  | 平滑回到录音画面                             |
| 9 秒    | 下一轮；首尾录音曲线一致                     |

进入引导自动循环，以 1.35 倍播放，实际约 6.67 秒一轮。左侧不显示“功能演示”或暂停／重播按钮，也不恢复参考图的箭头、暂停控件。logo＋Brevia、三状态圆点及横向五步导航保留。所有样例文字、标题和说明使用应用唯一的八语种词条，颜色跟随明暗主题。德文等较长内容可换行，卡片最小高度保留完整纪要。

减少动态效果时停在静态录音画面；窗口不可见或窄屏隐藏左栏时暂停，重新显示后继续，退出引导销毁时间轴和监听器。动画仅更新自身 DOM，不读写配置，不调用录音、权限、模型下载、AI、保存或手机服务。加速仅影响轮播，真实业务等待和处理时间不改动。

## 应用、预览与验证

完全退出已有 Brevia 后运行 `npm run start:fresh`，从第一步即可查看新版。所有五步只变化底部当前步骤与右侧设置，左侧动画始终一致。

[设计预览](videos/onboarding-motion/preview.html)共用实际应用组件、词条与动效。默认自动循环完整三画面；外围播放器允许分段、拖动及选择右侧页面底板，仅用于设计检查。`node scripts/sync-onboarding-preview.mjs` 自动同步生成快照，不手工修改生成文件。原九秒 HTML 与 `reference.png` 保留原字节。

检查范围：完整 `npm test`（包含实际 Electron E2E 与 362 项后端测试）、八语种×五个页面的三画面一致性、字幕和纪要词条、循环到终点后重新播放、1.35 倍速度、控件移除、右侧 DOM／配置不变、局部目标、快速语言切换、关闭清理及减少动态效果。实际应用截图位于 `output/playwright/onboarding-carousel/`。

当前预览八语种×五页×八个时间点共 320 帧，检查右侧与顶部像素不变及纪要完整显示。证据为 `.hyperframes/carousel-pixel-proof.json`，日志为 `self-check-carousel.log`；五个 HyperFrames 严格报告是 `check-carousel-{language,permissions,setup,ai,phone}.json`。源码、截图、检查结果和保留文件指纹见[本轮资产清单](revision-19-onboarding-assets.json)。
