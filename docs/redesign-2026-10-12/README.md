# Brevia 全页面设计图 · 2026-10-12

本轮重新设计桌面端与手机端的视觉语言、引导和完整功能页面。参考 [yovoice](https://github.com/leemysw/yovoice) 的真实工作台截图：白底、浅灰导航、细线分区、黑色主按钮与宽松阅读区。使用内置 imagegen 生成；桌面与手机实现已采用这套视觉语言，运行对照与检查记录见[实现与验证](implementation.md)。

覆盖范围已确认：桌面端与手机端全部页面。“左右风格”按桌面左导航、右内容设计。共 50 张有效画板：35 张桌面画板、15 张手机流程画板。D35 替代 D21 功能演示，M15 补全 M02 的实际准备字段。会议、人物、时间、配对码、容量和进度均为示例。图中的布局与状态供评审，精确功能边界、文案与尺寸以 [设计规范](design-specification.md) 为准。

桌面画板保留 1440×900 的源尺寸，应用默认按 8/9 等比例显示为 1280×800，字号、控件、图标与间距一起缩小。实际页面对照已按此默认窗口更新，手机画板与显示比例不变。

## 第二轮修订

已按反馈修订 12 张既有画板，新增 3 张任务与侧栏状态画板。

1. 语言选择覆盖简中、英、西、日、韩、法、德、俄全部 8 种语言。
2. 模型引导按现有具体模型多选下载，模型与存储保持同一步，下载流程不变。
3. 会议库为手机采集会议增加“手机录音”图标与来源标识。
4. 实时会议不展示说话人姓名或头像；会后精修身份能力保留。
5. 实时侧栏自动收起，悬停或键盘焦点进入时恢复，补齐两种状态。
6. 补齐任务类型、进度、暂停、失败、最小化与堆叠设计。
7. 手机会议暂停、重点、结束改为纯图标按钮，深色与离线录音同步修订。

全部修订约束见[设计规范](design-specification.md)，生成记录见[第二轮提示词](revision-02-prompts.md)。

## 第三轮：补齐引导页

新增独立的 AI 功能、AI 服务配置、手机安装与连接、设备配对、权限默认及拒绝恢复、手机按需授权画板。真实引导顺序为语言 → 权限 → 模型与存储 → AI 功能 → 手机连接 → 功能演示。

Android 安装卡片保留二维码与 APK 下载按钮；iPhone 使用 TestFlight 受邀安装，不表示正式上架。安装二维码与设备配对二维码分开。生成记录见[第三轮提示词](revision-03-prompts.md)。

## 第四轮：组件、操作与实际字段

先补图，再实现：D33 统一图标、按钮、输入、菜单与状态；D34 补齐工作区创建、编辑和删除确认；D35 将功能演示替换为五步导航与原尺寸阅读区域；D36 补齐本地 AI 模型选择与下载配置；M14 补齐记录重点；M15 补齐本地/已连接电脑的录音准备字段。

本轮[生成记录](revision-04-prompts.md)与[实现验证](implementation.md)单独记录。所有模型、状态、路径及二维码由现有接口提供；设计示例不作为接口数据。

## 使用限制

- 这些是静态设计图，不是可运行页面或已测量的 UI；imagegen 的中文、图标、尺寸和局部布局可能有偏差。
- 示意二维码不能用于连接，状态、版本、文件容量与百分比不代表真实运行数据。
- 手机仍负责采集、保存、传输和回看，电脑负责 AI 推理；不新增手机模型、账号或订阅流程。
- iOS 系统状态示意不等于承诺已实现 Live Activity；Android 更新交互不能复用于 iOS。
- 历史 `docs/mobile-design` 已从当前分支移除，仍可通过 Git 历史追溯；当前有效方案完整存入本目录。

提示词见 [PROMPTS.md](PROMPTS.md)。规范文件与画板名称一致，可分别打开大图检查。

D21 旧演示草稿已由 D35 替代，不列入有效图册。M02 的准备示意以 M15 的实际字段为准；其列表与空状态仍有效。D30 表示在线配置，D36 表示本地模型配置；其底图是上下文示意，不新增导航入口或产品能力。
