## 字体与图标

桌面系统栈：`-apple-system, "SF Pro Text", "Helvetica Neue", "PingFang SC", "Microsoft YaHei", Arial, sans-serif`。用户要求整体加粗后，正文/说明/普通按钮至少 500，原 500 层级升 600、原 600 升 700、已有 700 保持；全局 500，移除 `-webkit-font-smoothing: antialiased`。此为可读性调整，原 PNG 字体文件未知。

| 用途        | 当前桌面值 / 上下文                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------------------ |
| 常规标题    | 30px / 700；实时标题局部 28px / 36px 行高                                                              |
| 引导        | 品牌 64px / 700；标题 36px / 700，独立品牌栏比例                                                       |
| 阅读正文    | 16–17px，容器决定行高；字幕正文 16px、时间/翻译辅助 14px                                               |
| 控件 / 辅助 | 通常 14–16px / 500–600；辅助 13–14px                                                                   |
| 会议行      | 标题 16px / 600、分组 16px / 600、行最小 80px                                                          |
| SVG         | `interfaceIcon`：24 坐标系、1.6 线宽、currentColor；侧栏/返回常用 20px、收起录制栏 24px、任务操作 16px |

计时与百分比使用可比较的数字，长标题省略同时保留完整提示。任务标签与百分比分开布局，未知进度不伪造数字，外部文字保持转义。手机正式字体沿用 iOS SF / 其他平台 Roboto 与系统回退；捕获测试的 Arial Unicode 等本机字体不作为正式字体验收。

## D55/D56 双语版本日志

最终 PNG 外框约 x272–1008、y86–758；实现按 736px 宽、约 676px 高校准，不采用生成提示词中未实现的 720×580 估计。顶部 78px、正文内边距 24px、底部操作区约 78px、圆角 12px；正文 16px/24px、字重 500，分类 18px/700，标题与版本 24px/700。其字体字族、阴影和遮罩 `rgb(0 8 16 / 50%)` 为渲染校准后的推断，不能由 PNG 证明精确 CSS 参数。固定标题和操作，正文/历史版本独立滚动；小窗口通过高度约束保留全部正文与操作，不缩小文字。与 D41 共享日志内容，升级浮窗无品牌卡或旧日志卡片外框。

设备等待/审批弹窗统一 500px 宽、24px 内边距与 35% 中性遮罩；真实配对二维码保留 176px 以容纳真实信任载荷，不照搬原图的简化码。该功能延展和审批/拒绝/过期/引导状态的原生窗口验证见报告。

## 最后一轮共享校准

返回使用无横杆 chevron，编辑不附底部横线，复制使用双页线框；仍由同一 `interfaceIcon` 提供 24 坐标、1.6 线宽和 currentColor。主播放按钮统一 40px 黑色圆形与反相三角，迷你播放仍按所在卡片的尺寸约束；顶部语言入口已按用户标注移除，设置保留全部8种语言及持久化。

D51 收起侧栏内边距 10px、单个任务入口 52×44px、与设备分区相隔 14px；固定设备区 44px、设置入口 40px、底部内边距 8px。数量、计时、进度和失败提示来自现有任务节点；hover/键盘 focus 恢复完整列表。无任务时隐藏入口，不生成假进度。

D52 编辑页使用单栏，标题/全局导出各在原层级，取消/保存只有一组 36px 图标按钮。段落保持头像、姓名、时间及只读译文，文本域 16px/24px、8px/12px 内边距、8px 圆角；自动增高且不产生内层滚动条。版本切换在编辑中锁定，保存中锁定提交与取消，失败保留草稿并允许重试。上述几何来自最新实施约定与运行校准；字体名称、抗锯齿及浮层参数仍为推断。

首页副标题固定使用最新稿“所有对话，清晰归档。”，工作区优先展示实际描述。重复覆盖的 91 条声明、旧轮播动画和单卡缩略布局已移除，不再作为样式来源；深色、窄窗口、disabled 与错误样式继续保留。

录制标题栏的会议信息/更多并列，信息入口40px高、20px书签图标；只读信息面板借用菜单表面、320px宽/16px内边距/8px圆角，真实标题/工作区/语言不新增可编辑配置。该面板没有独立PNG，按一致性和真实状态验收。
