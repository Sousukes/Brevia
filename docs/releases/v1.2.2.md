# Brevia v1.2.2

2026-10-02

本次更新聚焦录音与数据安全、长会话稳定性，以及更清晰的双语更新日志。
This release focuses on recording and data safety, long-session stability, and clearer bilingual release notes.

## What's Changed

### 新增 / Features

- 迁移模型或录音目录时显示进度浮窗，并锁定冲突操作，迁移结束后自动恢复。<br>Storage moves now show a progress dialog and block conflicting actions until the move finishes. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 更新日志按类别展示，支持提交链接、新贡献者致谢和完整版本对比；历史版本可折叠查看。<br>The changelog now includes grouped changes, commit links, new contributor credits and a full comparison, with collapsible release history. ([2b36241](https://github.com/zerolovesea/Brevia/commit/2b36241a67c1855ae40809abdf237ec55a5f32d9))

### 改进 / Improvements

- 统一逐字稿的展示、编辑、翻译和导出版本选择，避免历史精修结果被模型状态变化覆盖。<br>Unified transcript selection across viewing, editing, translation and export, preserving historical refinements when model availability changes. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 声纹取样只读取所选音频片段，限制整段样本的内存加载；统一编辑器监听器、后台任务和侧车进程的生命周期。<br>Voiceprint learning reads only selected audio windows and bounds full-sample loading; editor listeners, background tasks and sidecar processes now share consistent cleanup rules. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 统一八语言文案与错误提示，保留配置表单和笔记编辑草稿，清理重复逻辑、失效样式和多余状态。<br>Consolidated copy and errors across eight languages, preserved configuration and note drafts, and removed duplicate logic, unused styles and redundant state. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))

### 修复 / Bug Fixes

- 修复批量删除与后台任务互斥冲突；部分操作失败时正确保留尚未处理的会议。<br>Fixed batch deletion conflicting with task safety checks; partially failed batches now retain unfinished meetings. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 修复结束录音失败后无法重试、恢复同名工作区返回空值，以及迁移数据目录后声纹样本路径失效的问题。<br>Fixed retrying a failed recording stop, restoring a deleted workspace by name, and voiceprint sample paths after data migration. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 导入、导出、翻译和声纹处理期间阻止冲突的数据清理；加强任务失败回滚与重复导出的文件名保护。<br>Protected imports, exports, translations and voiceprint processing from conflicting cleanup, and strengthened failure rollback and export filename reservation. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 修复快速切换页面、重复点击引导页和长会话残留监听器的问题；保留有效字幕时间戳与人工修改。<br>Fixed rapid navigation, repeated onboarding clicks and stale listeners in long sessions, while preserving valid transcript timestamps and manual edits. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 为 IPC 请求设置有限超时并加强输入校验，避免后端无响应时操作无限等待。<br>Added finite IPC deadlines and stronger input validation to prevent operations from waiting indefinitely on an unresponsive worker. ([45adfaf](https://github.com/zerolovesea/Brevia/commit/45adfaf))

- 修复取消 AI 推理时关闭已断开管道可能抛出异常的问题，确保子进程和两端管道均被回收。<br>Fixed a broken-pipe race when cancelling AI inference, ensuring the child process and both pipes are released. ([8f6e459](https://github.com/zerolovesea/Brevia/commit/8f6e4592dff69c9b74009a2f6def393b6d489481))
- 修复 Windows 并发保存配置时的文件替换冲突，按请求顺序写入并保留最后一次保存结果。<br>Fixed conflicting file replacements during concurrent configuration saves on Windows; writes now preserve request order and the last saved value. ([2c0f3bc](https://github.com/zerolovesea/Brevia/commit/2c0f3bc1baec6756a8007af264b8498ce4378932))

### 安全 / Security

- 加强存储路径、符号链接、归档导出和 IPC 输入校验；补齐三个 GGUF 模型下载文件的 SHA-256 校验。<br>Hardened storage paths, symlinks, archive exports and IPC validation, and added SHA-256 checks for all three GGUF model downloads. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
- 升级 js-yaml 依赖以纳入安全修复。<br>Updated js-yaml to include security fixes. ([6e6acc0](https://github.com/zerolovesea/Brevia/commit/6e6acc0a85d035fecb2587433d38ecc7c1570a8f))

### 行为变更 / Behavior Changes

- 录音导出统一为 WAV，移除 FLAC/M4A 选项；逐字稿和笔记的 Markdown、TXT、JSON、SRT、DOCX、PDF 导出保持可用。<br>Audio export is now WAV-only; FLAC/M4A options have been removed. Markdown, TXT, JSON, SRT, DOCX and PDF exports remain available for text content. ([4b1f51e](https://github.com/zerolovesea/Brevia/commit/4b1f51e088cf3f3f2c623e641c453a8a6f5d7724))
