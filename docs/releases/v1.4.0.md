# Brevia v1.4.0

全新桌面与手机界面，新增手机麦克风联动，完善跨平台录音、设备连接与断线补传。

Redesigned desktop and phone interfaces, phone microphone control, and more reliable cross-platform recording, device connections and upload recovery.

## 新增 / New

- 重构桌面主界面与首次使用引导，统一工作区、会议列表、实时字幕、笔记、播放器和设置的操作体验。<br>A redesigned desktop interface and onboarding bring a consistent experience to workspaces, meeting lists, live captions, notes, playback and settings.
- 桌面可选择已连接的手机作为麦克风，支持试音及从电脑开始、暂停、继续和结束录音。<br>Use a connected phone as the desktop microphone, preview its input level, and start, pause, resume or stop recording from the computer.

## 改进 / Improvements

- 统一明暗主题、多语言文案、键盘焦点和减少动态效果体验，完善不同窗口尺寸下的布局。<br>More consistent light and dark themes, translations, keyboard focus and reduced-motion behavior, with layouts adapted to different window sizes.
- 重新整理会议详情中的逐字稿、笔记、纪要编辑与导出入口，保留保存失败时的草稿并支持重试。<br>Reorganized transcript, note, summary editing and export controls in meeting details; drafts survive failed saves and can be retried.
- 手机端与桌面采用统一界面风格，完善配对、录音状态、连接错误及权限提示。<br>A shared visual style across phone and desktop, with clearer pairing, recording status, connection errors and permission guidance.
- Android 更新下载交由系统后台管理，离开页面后仍可继续；iOS 可检查 App Store 中的新版本。<br>Android update downloads continue through the system download manager after leaving the page; iOS can check for newer App Store versions.

## 修复 / Fixes

- 修复手机实时转写恢复后的字幕缺失、电脑重启后的控制状态恢复及断线补传边界问题，避免已确认音频被重复写入。<br>Fixed missing captions after restoring a phone session, recording control state after a desktop restart, and upload recovery edge cases, without rewriting acknowledged audio.
- 修复设置页切换时过期请求覆盖当前页面的问题；清理录音失败时保留索引，避免残留文件失去访问入口。<br>Stale settings requests no longer replace the current page; failed recording cleanup preserves the index so remaining files stay accessible.
- 修复部分 OpenAI 兼容服务的纪要与 AI 笔记请求，补齐接口路径并兼容模型名大小写；修复暗色主题开关图标（感谢 @Sousukes，PR #9）。<br>Fixed summary and AI note requests to stricter OpenAI-compatible services, including endpoint paths and model-name casing, plus the dark-theme switch icon (thanks to @Sousukes, PR #9).
- Windows 本地 AI 运行库固定使用 AVX2 并禁用 AVX512；模型加载或推理失败后回收独立进程，减少异常重试残留的内存。<br>Windows local AI builds use AVX2 with AVX512 disabled; failed model loads or inference release the sidecar process to reduce memory retained across retries.
- 修复搜索结果异步覆盖、纪要标题与列表粘连、批量导出结果反馈，以及弹出菜单重复监听等问题。<br>Fixed stale search results, joined summary headings and list items, batch export result reporting, and duplicate popover listeners.
- 修复英文设备连接页在默认窗口尺寸下的溢出，清理连接卡片的重复间距。<br>Fixed overflow on the English device connection page at the default window size by removing duplicate card spacing.

## 安全 / Security

- 加强 Markdown 图片地址的属性转义，阻止恶意内容注入页面事件属性。<br>Hardened attribute escaping for Markdown image URLs to prevent malicious content from injecting page event handlers.

## 使用说明 / Notes

- v1.4.0 是桌面版本号；手机端功能随配套移动构建分发，iOS 正式上架与更新仍取决于 Apple 审核。<br>v1.4.0 is the desktop version; phone features ship through companion mobile builds, and iOS availability and updates remain subject to Apple review.
- 手机麦克风联动需要已配对、已连接且在前台就绪的配套手机应用；实时转写与 AI 处理仍由电脑完成。<br>Phone microphone control requires the companion app to be paired, connected and ready in the foreground; live transcription and AI processing still run on the computer.
- 断线期间音频继续保存在手机，恢复连接后续传已授权的录音；来电、强制退出和系统限制仍可能中断录音，结束后的补传可能需要保持手机应用在前台。<br>Audio remains on the phone during a disconnection and authorized uploads resume after reconnection. Calls, force-stop and system limits can still interrupt recording; uploads after recording may require keeping the phone app in the foreground.
